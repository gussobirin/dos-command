Command for Network

Perintah jaringan pada Command Prompt

Identitas

Tujuan Pembelajaran

  • Menjelaskan fungsi perintah jaringan: ipconfig, ping, tracert, nslookup, netstat, dan arp.
  • Menggunakan perintah tersebut untuk memeriksa konfigurasi dan konektivitas jaringan.
  • Menganalisis hasil perintah untuk menentukan penyebab gangguan jaringan.

Perintah jaringan dijalankan lewat Command Prompt (CMD), antarmuka berbasis teks yang mewarisi cara kerja DOS.

Kegiatan 1Pahami Konsep

Pilih satu jawaban. Jawaban langsung diperiksa dan dikunci.

Kegiatan 2Cocokkan Perintah

Pasangkan perintah dengan fungsinya.

Kegiatan 3Praktik di Terminal Jaringan

Kamu berada di komputer PC-TJKT-07 (IP 192.168.10.25, gateway 192.168.10.1). Ketik perintah di terminal simulasi dan selesaikan semua misi.

    C:\Users\SISWA>

    Petunjuk dan target yang bisa dicoba
    hostnameNama komputer
    ipconfigKonfigurasi IP (tambahkan /all untuk detail)
    ping targetUji koneksi, contoh ping 192.168.10.1 (opsi -n 2 mengatur jumlah paket)
    tracert targetTelusuri rute ke tujuan
    nslookup domainCari IP dari nama domain
    netstat -anKoneksi dan port aktif
    arp -aTabel IP dan MAC address
    Target192.168.10.1 192.168.10.10 192.168.10.30 192.168.10.99 127.0.0.1 google.com server.tjkt.local

    Kegiatan 4Studi Kasus Troubleshooting

    Analisis hasil perintah, lalu pilih penyebab yang paling mungkin.

    Kegiatan 5Analisis dan Refleksi

    Jawab dengan kalimatmu sendiri. Bagian ini dinilai oleh guru.

    1. Sebuah komputer tidak bisa membuka website. Urutkan langkah pemeriksaan yang kamu lakukan dan sebutkan perintah yang dipakai pada tiap langkah.

    2. Jelaskan perbedaan ping dan tracert, serta kapan masing-masing digunakan.

    3. Refleksi: perintah mana yang paling berguna bagimu dan mengapa? Bagian mana yang masih membingungkan?

    Rekap Hasil

    Nilai otomatis hanya dari Kegiatan 1–4. Kegiatan 5 dinilai guru.
