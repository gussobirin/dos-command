Kegiatan 3Praktik di Terminal DOS

Ketik perintah di terminal simulasi, lalu selesaikan semua misi. Misi akan tercentang otomatis.

    C:\>

    Petunjuk perintah
    DIRDaftar isi direktori aktif
    CD namaMasuk folder (CD .. naik satu tingkat, CD \ ke root)
    MD namaBuat folder
    ECHO teks > file.txtBuat berkas berisi teks
    TYPE fileTampilkan isi berkas
    COPY asal tujuanSalin berkas
    DEL fileHapus berkas
    REN lama baruGanti nama · RD hapus folder kosong · CLS bersihkan layar

    Kegiatan 4Analisis dan Refleksi

    Jawab dengan kalimatmu sendiri. Bagian ini dinilai oleh guru.

    1. Jelaskan perbedaan perintah DEL dan RD beserta contoh penggunaannya.

    2. Mengapa teknisi jaringan masih perlu menguasai antarmuka berbasis perintah (CLI) meskipun sudah ada GUI? Berikan minimal 2 alasan.

    3. Refleksi: bagian mana yang paling mudah dan paling sulit bagimu hari ini? Apa langkahmu untuk memperbaikinya?

    Rekap Hasil

    Nilai otomatis hanya dari Kegiatan 1–3. Kegiatan 4 dinilai guru.
